# Real photograph references

These are public photographs of instruments/pipework, not synthetic display drawings.
They are illustrative references, not photographs of the simulated FaultTrace plant.
Neither image identifies F-17 or V-08, proves a current field measurement, or authorizes correction.

- Digital pressure meter: Nick.follows, own work, 4 May 2019. [Source](https://commons.wikimedia.org/wiki/File:C9557_01_1200_RGB_300dpi.jpg).
- Household ball valves: NVgt156, own work, 28 May 2019. [Source](https://commons.wikimedia.org/wiki/File:Ball_valve_in_household.jpg).

Both images are licensed separately under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Their image license does not change the application code license. Attribution and source links
appear beside each image in the application. We downloaded Wikimedia thumbnails unchanged;
no cropping, retouching, generated labels, or compositing was performed by FaultTrace.
Exact download URLs, sizes and SHA-256 hashes are in provenance.json.

The meter image includes multiple instruments and mBar markings. It is deliberately not a
known-good 180 kPa differential-pressure sample. A model must preserve uncertainty, unsupported
units and ambiguous measurement modes rather than manufacture a compatible F-17 reading.
No live NVIDIA accuracy claim has been established for either photograph.
